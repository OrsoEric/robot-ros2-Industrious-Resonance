# Latte Panda Mu N100 8GB - Ubuntu 24 - OpenVINO

Intel is one of two manufacturers in the world that bother making drivers and runtimes for ML framework, the only other being Nvidia.

AMD tries, but fails spectacularly. As 2025-09 AMD finally has a nightly that promises support for their GPU under windows. That's how bad it is.

The crux of the problem is that nobody made ONNX or Pythorch runtimes for Vulkan which works pretty well on every GPU.

I'll try OpenVINO

## Prepare python UV


``` bash
uv venv OPENVINO_ENV --python 3.12

source OPENVINO_ENV/bin/activate

uv pip install openvino
```

## Install OpenVINO Runtime

[Instructions](https://docs.openvino.ai/2025/get-started/install-openvino/install-openvino-apt.html)

``` bash
wget https://apt.repos.intel.com/intel-gpg-keys/GPG-PUB-KEY-INTEL-SW-PRODUCTS.PUB

sudo gpg --output /etc/apt/trusted.gpg.d/intel.gpg --dearmor GPG-PUB-KEY-INTEL-SW-PRODUCTS.PUB

echo "deb https://apt.repos.intel.com/openvino ubuntu24 main" | sudo tee /etc/apt/sources.list.d/intel-openvino.list

sudo apt-get install gnupg

sudo apt update

sudo apt install openvino

```
